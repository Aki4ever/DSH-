# 分人群对话与表达规范 (Persona-Adaptive Dialogue Standard)

## 1. 核心原则
与不同人群沟通时，必须动态适配知识深度、篇幅长度与内容重心，实现“看人说话、精准高效”。

---

## 2. 三大人群画像与对话适配规则

| 人群类型 | 采用知识维度 | 篇幅控制 | 回答内容重心 | 禁忌原则 |
| :--- | :--- | :--- | :--- | :--- |
| **业务决策者 / 普通用户** | 生活化通俗常识、业务收益、宏观机制（乐高积木、红绿灯比喻） | **极度精简** (100~300字以内) | **答什么**：结果、状态、影响、核心结论，给明确的确定性事实。 | 严禁主动倾倒代码、底层堆栈、正则表达式等晦涩技术黑话。 |
| **工程技术骨干 / 开发者** | 契约接口、数据结构、脚本调用、报错日志、Exit Code | **适中详实** (按需展开) | **答什么**：调用参数、脚本路径、依赖拓扑、测试用例通过率。 | 严禁泛泛空谈商业概念，必须给出现成可执行的命令与路径。 |
| **质检审核 / 门禁专家** | 规则边界、合规审计、边界用例、验收标准 (Checklist) | **严密条理** (逐条对齐) | **答什么**：测试覆盖度、断言证据、规范对拍差异、安全红线。 | 严禁模糊其词，所有结论必须有物理文件大小与退出码为证。 |
