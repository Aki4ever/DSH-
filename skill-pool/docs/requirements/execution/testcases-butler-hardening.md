## 6. 实施过程中对需求的修正记录

| 编号 | 原描述 | 实际实现 | 原因 |
| :--- | :--- | :--- | :--- |
| AMEND-9 | 树要求「每个 catalog 技能恰好出现一次」 | 改为 **L3 恰属一个集群；L1/L2 至少被一个父级引用；无环** | composition 是 DAG，同一个原子（如 `output-chinese-only`）会被多个父级复用，「恰好一次」在物理上不成立 |
| AMEND-10 | 缩写判据「12 字内无中文即违规」 | 增加第二条子判据「同一缩写首现必须带中文释义结构」 | 按字面实现时「使用 MCP 完成」因后文紧跟中文不会命中，与验收要求冲突 |
| AMEND-11 | 「白名单外拉丁词 = 0」未限定适用范围 | 明确门禁对象为**交付回复正文**；命令参考类文档不在范围内；标识符模式白名单已补齐（见 FIX-05） | 实测把门禁套到 `docs/operations/workflows.md` 会判 exit 1（`cjk_ratio` 0.7490），因为该文档天然含大量命令、路径与 `REQ-*` 编号——这是白名单覆盖不足，不是文档不合格 |
