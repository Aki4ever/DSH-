# Format Iconized Tail (尾部特异化图标规约)

## Overview

本技能是 L1 原子级基础规约。确保任务最终总结严格集中于答复最末尾，并强化特异化视觉图标。

## Strict Rules

1. **尾部集中输出**：交付框架必须整体收敛在全文的最末尾；
2. **图标与状态语义硬绑定**：
   - 🚀 **【当前状态】**：必须明确给出具体的工程实施阶段状态枚举（如 `【已实施】`、`【规划中】`、`【实施中】`、`【已阻断】`），严禁仅输出“当前状态”四个字；
   - 🎯 **【索引命中】**：列出本次查询命中的主要 Skill 标识与分类；
   - ⏱️ **【路由时长】**：真实物理提取与路由检索的耗时（如 `0.72ms`）；
   - 📦 **【输出物】**：本次产生的物理交付物清单（无产物时不出现）；
   - 📍 **【输出地址】**：物理验证通过的真实路径（无产物时不出现）；
   - 💡 **【核心结论】**：仅在无产物分支出现，提炼高浓度业务结论；
   - 📌 **【重要说明】**：强相关的运行验证命令与注意事项；
3. **严禁混杂散布**：正文中间用于推进分析与执行，图标框架严禁在正文穿插混杂。
