# Concise Focused Output (默认简短聚焦规约)

## Overview

本技能是 L1 原子级基础规约。消灭大模型无节制铺陈展开、篇幅臃肿的毛病。

## Strict Rules

1. **默认简短**：若用户未显式要求“详细方案”、“展开说明”或“长文报告”，输出必须保持精炼紧凑；
2. **直击核心**：开门见山给出结论与行动步骤，删除所有的背景铺垫与寒暄套话；
3. **分点清晰**：并列信息优先使用结构化短句呈现，单条要点控制在两句话以内。
