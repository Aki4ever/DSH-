# Filter Conversational Noise (过滤对话噪音规约)

## Overview

本技能是 L1 原子级基础规约。在理解用户输入时，强行剥离“你好、请问、能不能、帮我、我想、啊、哈、呢、吧、哎呀、谢谢”等所有无意义填充词，仅保留真正表达意图的内容主干。

## Strict Rules & Blacklist

- 问候客套：`你好`, `您好`, `请问`, `麻烦`, `劳驾`, `谢谢`, `拜托`, `可不可以`, `能不能`
- 语气助词：`啊`, `呀`, `吧`, `呢`, `哈`, `呗`, `哦`, `嗯`, `嘛`, `啦`
- 情绪填充：`随便`, `随便搞搞`, `那个啥`, `我说`, `就是说`
