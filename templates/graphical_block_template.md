# DSH 原生图形化区块组件模板 (Graphical Block Template)

本文档是针对 DSH 聊天界面定制的**零乱码原生图形化卡片组件原型**。严禁使用 `<div>`、`<details>` 等裸 HTML 标签，统一采用 GFM 引用与分割线构建。

---

## 📌 一、核心置顶卡片原型 (Top Banner)

```markdown
> ### 📌 **核心置顶结论** `[ 状态：已激活 ]`
> ┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈
> - **当前任务**：`[分类编号][难度分] 8字以内概述`
> - **核心动作**：首动已执行 `./scripts/rename_session.sh`
> - **交付结论**：这里是核心结论要点（通俗直白大白话）
```

---

## 🗂️ 二、段落区块化卡片原型 (Block Accordion)

每个独立的大段落必须用一个带前缀图标的独立引用块封装：

```markdown
> #### 🔍 **第一区块：背景与问题分析** `[ ▼ 核心正文 ]`
> ────────────────────────────────────────────────────────────
> 这里是分析正文，支持使用列表和代码：
> - 关键点 1
> - 关键点 2

> #### 📋 **第二区块：标准化实施方案** `[ ▶ 详情展开 ]`
> ────────────────────────────────────────────────────────────
> 这里是方案正文...

> #### 🚀 **第三区块：落地与质检结果** `[ 🏁 验收通过 ]`
> ────────────────────────────────────────────────────────────
> 这里是质检成果与交付路径...
```
