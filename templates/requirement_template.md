# 结构化需求标准卡片模板 (Requirement Template)

本模板为项目所有新增与演进需求的**唯一标准录入格式**。任何需求录入必须填齐以下字段，确保信息完整、结构统一、便于追溯。

---

### REQ-XXX: [简明需求名称]

- **当前状态**：`[ACTIVE]` 生效中 / `[EVOLVING]` 演进中 / `[DEPRECATED]` 已废弃
- **实施版本**：`vX.Y.Z` (遵循 [`rules/workflow/versioning_standard.md`](../rules/workflow/versioning_standard.md))
- **提出时间**：YYYY-MM-DD
- **最新更新**：YYYY-MM-DD
- **责任归属**：AI 智能体 / 用户

#### 1. 提出背景与痛点
- 说明该需求产生的实际场景；
- 阐明当前存在的具体问题或缺失。

#### 2. 核心诉求与目标
1. 目标一：具体要达成的效果；
2. 目标二：遵循的具体约束与原则。

#### 3. 关联文件与影响范围
- **主规则文件**：`rules/...`
- **配套文档**：`docs/...`
- **关联模板/脚本**：`templates/...` 或 `scripts/...`

#### 4. 验收标准
- [ ] 验收点一：明确且可检验的结果；
- [ ] 验收点二：文档与规则双向同步完成；
- [ ] 验收点三：无冲突残留与旧文件污染。

#### 5. 历史演进与变更记录
- **YYYY-MM-DD [操作类型: 新建/优化/废弃]**：记录具体修改要点与原因。
