# 全局规则工程 (Global Rules Project)

本项目用于集中管理、统一维护全局各类运行规范、指令规则、工作流标准及模板资产。

---

## 📁 目录结构说明

```text
.
├── rules/                  # 核心规则目录
│   ├── system/             # 系统级与通用全局规则
│   ├── workflow/           # 工作流与流程协同规范
│   ├── coding/             # 开发与代码工程规范
│   └── security/           # 安全与合规准则
├── docs/                   # 项目说明与配套设计文档
├── templates/              # 规则模板、提示词模板及标准化样式
├── scripts/                # 自动化校验、格式化或规则同步脚本
├── .gitignore              # Git 忽略文件规则
├── .gitattributes          # Git 文本格式与换行规范
└── README.md               # 项目主说明文档
```

---

## 🚀 快速上手

### 1. 规则新增与维护
- 新增规则文件请归类放入 `rules/` 下对应的分类目录；
- 通用或标准格式参考 `templates/` 目录中的标准模板；
- 规则变动建议遵循清晰的 Git 提交记录。

### 2. Git 分支管理
- **main**: 稳定主分支，仅保留已验证生效的规则；
- **feature/* / rule/**: 新规则研发或重大修订分支。
