## 📊 一、六维效率量化审计指标模型 (The 6-Metric Efficiency Framework)

| 指标代码 | 指标中文名称 | 定义与计算逻辑 | 合格基准线 | 优化意义与导向 |
| :---: | :--- | :--- | :---: | :--- |
| **M1** | **意图收敛度 (Convergence Rate)** | 是否首轮命中高权重干道（G0/G1）并确立唯一目标 (100% / 0%) | 100% | 避免在低级小道上泛化漫游 |
| **M2** | **首动命名履约率 (Handshake Compliance)** | 首轮是否将 `./scripts/rename_session.sh` 作为首个工具调用 (100% / 0%) | 100% | 彻底杜绝侧边栏标题丢失与截断 |
| **M3** | **工具调用有效率 (Tool Efficiency Ratio)** | 有效推进工具数 / 总工具调用数 (有效率 %) | ≥ 85% | 压制重复盲读、报错死循环与无效试错 |
| **M4** | **写后读回覆盖率 (Read-Back Ratio)** | 执行写操作后经过读回验证的文件数 / 总写文件数 | 100% | 保障免审批环境代码与配置完整性 |
| **M5** | **流程步骤完整度 (Process Compliance)** | 严格执行十六步工序并输出回执的比例 | 100% | 消除脑内跳步与非受控黑盒执行 |
| **M6** | **交付入口直达度 (Entrypoint Directness)** | 交付物是否包含可点击/可执行的直达组件 (100% / 0%) | 100% | 实现用户零查找、开箱即用体验 |
