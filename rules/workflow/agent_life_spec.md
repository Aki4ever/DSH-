# 全局流程管控 Agent Life 规范 (Agent Life Orchestration Specification)

> ### 🏷️ **版本信息与实施追踪**
> - **当前文档版本**：`v4.21.0`
> - **对应实施版本**：`v4.21.0`
> - **版本治理规范**：遵循 [`rules/workflow/versioning_standard.md`](versioning_standard.md)
> - **需求依据**：`REQ-055` / `CR-010`（全局流程调度 Agent Life 与阶段原子反馈）
> - **生效状态**：`[Release 稳定生效]`

本文档确立了工程全域任务执行的**最高流程调度中枢智能体 `Agent Life`（生命周期调度器）**。Agent Life 负责对整个任务生命周期实施全局把控，裁决“流程去向何处、当前执行什么、下一步调度谁、何时申领与释放资源冲突锁”。

---

## 🧭 一、Agent Life 核心架构与职责模型

```text
 ┌─────────────────────────────────────────────────────────────┐
 │                    调度中枢: Agent Life                      │
 │    - 状态机感知: 跟踪 S01~S16 当前流转位置                    │
 │    - 锁事务总管: 自动申请/释放 scripts/global_scheduler_lock.sh  │
 │    - 门禁裁判长: 驱动 control_gates.sh 累积放行               │
 └──────────────┬──────────────────────────────▲───────────────┘
                │ 下发下一阶段任务              │ 阶段原子性完成反馈
                ▼                              │ (Stage Receipt)
 ┌─────────────────────────────┐┌──────────────┴───────────────┐
 │ 执行工人/子阶段 (Worker/Stage)││ 阶段验收探针 (Atomic Probe)    │
 └─────────────────────────────┘└─────────────────────────────┘
```

### 1. 四大核心天职
1. **任务调度句柄锚定 (Task Dispatch Handle Anchor)**：调度中枢执行任何派发、交接或锁申领前，必须校验任务会话是否已完成标准改名（`[分类编号][难度分] 8字概述`）；以此名称作为全局唯一指代句柄（Handle），严禁未命名裸跑或匿名调度；
2. **时序控制权**：作为最高流水线中枢，严格判定任务阶段合法性，杜绝跳步（如未探明环境直接写代码）；
3. **全局调度锁接管**：在只读阶段保持并发共享；进入写操作阶段（写入/修改文件、Git 提交）前，由 Agent Life 统一向 `scripts/global_scheduler_lock.sh` 申领排他独占锁（Lock ID 绑定任务名称），并在阶段收尾验收完成后安全释放；
4. **下一步裁决 (Next Action Dispatcher)**：每个工序结束时，由 Agent Life 明确输出“当前执行完毕，下一步调度执行 [工序号+动作]”。

## 📬 二、阶段原子性完成反馈机制 (Atomic Stage Feedback)

执行工人在完成具体阶段任务后，不得直接跳入下一阶段，必须向 `Agent Life` 发送标准的**【阶段原子反馈回执 (Stage Receipt)】**：

```markdown
### 📬 阶段原子回执 (Stage Feedback Receipt)
- 🏷️ **任务句柄**：`[优规014][45] 任务改名层级同步`（法定唯一指代）
- 📌 **完成阶段**：S04-筹策与技术方案
- ⏱️ **执行耗时**：1.5s
- 📄 **产出物清单**：`docs/plan.md`（已读回校验完毕）
- 🔒 **资源锁状态**：排他锁已持有（Lock ID: `lock-[优规014]`）
- 🚦 **阶段门禁断言**：测试全绿，无外部依赖断链
- 🔄 **上报状态**：请求 Agent Life 调度下一工序
```

Agent Life 校验回执后，执行仲裁并输出下一步调度指令。

## 🛠️ 三、Agent Life 辅助调度引擎

系统提供轻量级调度辅助脚本：
```bash
node scripts/agent_life.mjs --status            # 查看当前任务生命周期阶段与锁状态
node scripts/agent_life.mjs --step <S01~S16>    # 提交阶段回执并推进至下一步
```
