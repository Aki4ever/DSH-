# rules 目录说明

## 📌 目录定位
- **路径**: `rules/`
- **主要作用**: 存放全局规则法典，是智能体行为的"法律条文"总库。所有规则按性质分门别类，一处修改即全域生效。

---

## 📂 分层结构

| 子目录 | 定位 | 收录内容 |
| :--- | :--- | :--- |
| `system/` | 系统级基础规则 | 元规则、思考框架、语言标准、初始化协议 |
| `workflow/` | 流程协同规范 | 任务执行流、风险揭示、复盘进化、版本治理 |
| `coding/` | 代码与工程规范 | 测试门禁、Unity 工程标准、原子性规范 |
| `security/` | 安全防护红线 | 免审批安全基线、防破坏红线、写后读回 |

---

## 📋 收纳规范
1. 新规则必须先查重（见 `workflow/change_flow.md`），杜绝碎片化冗余；
2. 每条规则文件须在 `docs/requirements.md` 有对应需求依据；
3. 规则文件标题采用「中文名 (English Name)」双语形制；
4. 涉及阈值的规则，同步登记到 `ai-control/config/gates.conf`（如适用）。

---

## 🛠️ 维护原则
- 遵循 `system/meta_rules.md` 最高准则；
- 规则变更走 `workflow/change_flow.md` 六步循环；
- 保持文档全中文、通俗直白、无生僻字。
