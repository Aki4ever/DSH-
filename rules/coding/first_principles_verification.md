本文档确立了工程全域在技术探索、方案论证、问题排查与功能声明时的**底层认知法则**：回归物理本质与第一性原理，彻底杜绝轻信二手信息与外部转述，凡事必须建立物理实证与可复现推论。

---

## 🔬 一、第一性原理三不采信原则 (Zero-Trust Claims)

任何方案或结论在未经机器物理证明前，必须执行以下“三不采信”：
1. ❌ **不采信二手转述**：论坛、社群讨论、第三方非官方博客的经验总结，不得作为事实依据；
2. ❌ **不采信静态宣称**：文档中写着“已支持”或模型自述“已跑通”，未出具真实物理 Exit Code 或测试日志前，一律视为未经验证的假设；
3. ❌ **不采信表面相关**：禁止将时间先后或偶发性通过直接断言为因果关系，必须探明底层机械原理。

## 📐 二、第一性原理实证调查五步法 (Empirical Five-Step Method)

```text
 ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
 │  1. 本质还原  │ ──> │  2. 剥离假设  │ ──> │ 3. 最小探针  │
 └──────────────┘     └──────────────┘     └──────┬───────┘
                                                  ▼
                      ┌──────────────┐     ┌──────────────┐
                      │ 5. 实证闭环  │ <── │ 4. 采集实况  │
                      └──────────────┘     └──────────────┘
```

1. **【析】(本质还原)**：抛弃既有术语包装，将问题拆解到最基础的数理、操作系统、物理内存或文件协议层；
2. **【剥】(剥离假设)**：将“别人说的话”与“机器给的报错”严格分离，列出所有未经实测的先验假设；
3. **【探】(最小探针)**：构造一段最小可执行脚本（Minimal Reproduction Probe）或极简单元撞测用例；
4. **【采】(采集实况)**：直接观察真实的物理输出：进程退出码（Exit Code）、HTTP 响应体、系统底层返回值；
5. **【断】(实证闭环)**：基于实况形成确定性结论（L1 证据），或依有限状态机推导出已证实的必然结论（L2 证据）。

---

## 🏷️ 三、论据证据三级定级标准 (Evidence Hierarchy)

| 等级 | 标识 | 定义范畴 | 采信策略 |
| :---: | :---: | :--- | :--- |
| **L1** | 🟢 **物理实证** | 本地命令实跑输出、机器退出码 0、磁盘物理文件读回、官方源码契约行号 | **完全采信**，可直接作为阻断依据与终局结论 |
| **L2** | 🟡 **严密推论** | 基于 L1 证据，通过逻辑演绎、语法 AST 解析或状态机转移得出的唯一解 | **附推导链采信**，必须在说明中写清推论步骤 |
| **L3** | 🔴 **外部转述** | 口头经验、网络文章、未经实测的文档宣称、猜想假设 | **绝不采信**，必须构造探针实测降维成 L1 后方可使用 |
