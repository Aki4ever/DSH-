## ⚡ 二、六大扩展能力维度详述与选型精选

### 1. 协议标准扩展：Anthropic 主导的 MCP (Model Context Protocol)

MCP 是目前业界发展最迅猛、最具通用性的开放标准协议，彻底解决了“每个工具都要写一套专属胶水代码”的碎片化痛点。

#### (1) 核心通信机制与原语
- **通信模式**：支持标准进程管道输入输出 (`stdio`) 与 HTTP 长连接/服务端事件流 (`SSE/HTTP`)；
- **三大核心原语 (Primitives)**：
  - **Tools (可执行工具)**：暴露给大模型调用的具名函数（带 JSON Schema 校验）；
  - **Resources (只读上下文资源)**：类似文件的只读数据源，模型可直接挂载为上下文；
  - **Prompts (交互模板)**：服务器预设的高质量交互提示词模板。

#### (2) 官方与社区精选顶级 MCP Servers 清单

| MCP Server 标识 | 核心职能与场景 | 接入模式 | 适用业务价值 |
| :--- | :--- | :---: | :--- |
| **`@modelcontextprotocol/server-filesystem`** | 安全沙箱受限目录读写 | `stdio` | 控制智能体在指定物理目录读写，防越权逃逸 |
| **`@modelcontextprotocol/server-git`** | Git 仓库深入分析与日志溯源 | `stdio` | 自动化生成 Release Notes、冲突排查与代码溯源 |
| **`@modelcontextprotocol/server-memory`** | 基于知识图谱的持久记忆 | `stdio` | 跨会话沉淀实体关系（Entity-Relation）图谱 |
| **`@modelcontextprotocol/server-postgres`** | PostgreSQL 数据库交互与查询 | `stdio/SSE` | 智能体直接执行只读 SQL 探索 Schema 与分析报表 |
| **`@modelcontextprotocol/server-fetch`** | 通用网页抓取与 HTML 转纯文本 | `stdio` | 提取外部在线文档、API 手册与技术文章 |
| **`@modelcontextprotocol/server-github`** | GitHub 仓库、PR、Issue 自动化 | `stdio` | 自动发起 PR、检阅 Pull Request、分配 issue |
| **`@modelcontextprotocol/server-puppeteer`** | 无头浏览器控制与网页截屏 | `stdio` | Web 界面自动化测试、UI 回归对比、动态 SPA 抓取 |
| **`mcp-server-docker`** | Docker 容器生命周期管控 | `stdio` | 自动启停测试容器、构建微服务镜像、抓取容器日志 |
| **`mcp-server-brave-search`** | 实时互联网网页检索与摘要 | `stdio` | 为智能体补充高时效性外部互联网信息 |

### 2. 动态专家技能挂载：Agent Skills

区别于启动时即锁定的静态工具，**Skill** 具备“按需动态挂载、执行完毕卸载”的特性，能够显著降低模型上下文负载。

- **核心机制**：通过 DSH 原生 `skill(name)` 接口，当收到特定垂直领域任务时（如“分析 Unity 内存泄漏”或“审核法律合同”），动态加载预设的完整指令包与专有子函数；
- **典型扩展方向**：
  - **代码审查专家技能 (`code-reviewer`)**：包含静态代码扫描规范与坏味道规则；
  - **Unity 资产审计技能 (`unity-auditor`)**：自动检查 .meta 同步与贴图尺寸越界；
  - **长文档结构化萃取技能 (`doc-extractor`)**：专攻百页 PDF/Word 核心信息提炼。

### 3. 系统级工具链：优质 CLI (Command-Line Interface) 生态

智能体天然拥有终端（Bash）执行能力，Unix 哲学（“做好一件事并支持管道连接”）的 CLI 工具是性价比最高、性能最强的能力扩充路径。

| CLI 工具名称 | 核心命令与职能 | 协同与接入方式 | 生产力收益 |
| :--- | :--- | :--- | :--- |
| **`gh` (GitHub CLI)** | `gh pr create` / `gh issue list` | Bash 直接调用 | 彻底告别打开浏览器点点点，全命令流转 Git 工作流 |
| **`jq` / `yq`** | `cat data.json \| jq '.items[0]'` | 管道流式解析 | 毫秒级提取超大 JSON/YAML 指定字段，避免爆上下文 |
| **`ripgrep` (`rg`)** | `rg "pattern" src/ -t cs` | 代码全文毫秒检索 | 比普通 grep 快 10~50 倍，超大型项目代码检索神器 |
| **`ffmpeg`** | 视频转码、截取关键帧、抽音频 | Bash 多媒体管道 | 配合视觉模型快速完成游戏录屏异常画面诊断 |
| **`pandoc`** | Markdown / HTML / PDF / Word 互转 | 格式转换引擎 | 一键将工程规范导出为排版精美的 PDF 交付物 |
| **`docker` / `colima`** | 轻量本地容器引擎 | 隔离测试环境 | 在纯净容器内运行不可靠脚本，确保宿主安全 |

### 4. 自动化接口反射：OpenAPI / Swagger 自动转 Tool

- **痛点解决**：如果项目有现成的后端 RESTful 服务，无需手动逐个封装每个 API 的接口代码；
- **机制原理**：利用 OpenAPI 3.0 / Swagger JSON 描述文件，通过解析器自动将每个路径（如 `POST /api/v1/users`）反射生成标准 Agent Tool Definition（自动提取 `description`、`parameters` 与 `types`）；
- **落地价值**：开发人员只要维护一份 Swagger 文档，AI 就能自动具备操控全套业务后台的能力。

---

### 5. 交互式感知扩展：Playwright / Puppeteer 无头浏览器

- **核心场景**：
  - 前端 Web GUI 页面回归测试（如自动化点击 DeepSeek Harness Web 界面）；
  - 遇到需要执行复杂 JavaScript 渲染的反爬网页时，直接加载动态页面并提取渲染完成后的 DOM 树；
  - 自动对网页进行区域截图，回传给 `read_image` 视觉模型进行 UI 布局与样式审查。

## 📊 三、六大扩展维度横向对比矩阵

| 扩展维度 | 接入与维护成本 | 隔离与安全性 | 执行响应性能 | 生态丰富度 | 适用核心场景 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **MCP 协议** | **低**（标准协议即插即用） | **高**（进程级管道隔离） | **极高**（本机通信） | **爆发式增长** | 跨工具链统一标准接入、数据库与外部协同首选 |
| **Agent Skills** | **极低**（纯文本指令沉淀） | **极高**（无外部进程风险）| **瞬时**（内存加载） | **依赖自主积累** | 垂直业务规则、复杂分析 SOP 指导 |
| **CLI 命令行** | **低**（系统包管理器安装） | **中**（需沙箱自律保障） | **极致**（原生二进制） | **海量开源积累** | 代码审查、文件重构、Git运维、多媒体处理 |
| **OpenAPI 反射** | **中**（需维持文档规范） | **高**（走 HTTP 网关鉴权） | **高**（标准 REST） | **全行业通用** | 企业内部业务系统、云平台控制台接入 |
| **无头浏览器** | **中**（需安装 Chromium 内核）| **高**（独立浏览器沙盒） | **中**（渲染消耗内存） | **成熟稳定** | 动态页面数据采集、端到端自动化 UI 测试 |

## 🚀 四、DSH 宿主能力落地推荐路线 (Actionable Roadmap)

1. **第一优先级（即刻推荐）**：
   - 充分激活本机已有的 **CLI 工具链**（`gh`, `jq`, `ripgrep`），通过标准化任务流直接产生生产力；
   - 沉淀 **DSH 垂直业务 Skills**（如 Unity 规范自检 Skill、需求查重 Skill）。
2. **第二优先级（中短期接入）**：
   - 引入 **MCP 核心 Servers**（如 Filesystem, Fetch, Git, PostgreSQL），作为 DSH 宿主执行层的标准化外部插件源；
3. **第三优先级（根据项目需求引入）**：
   - 引入 **Playwright** 开展 Web 自动化，对接业务系统 OpenAPI 反射工具。
