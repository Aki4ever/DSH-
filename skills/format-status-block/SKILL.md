# Format Status Block (状态板块规约)

## Overview

本技能是 L1 原子级基础规约。规范所有最终答复中的第一部分“当前状态”。

## Strict Rules

1. **固定标题与特异化图标**：必须以 `🚀 【当前状态】` 作为板块锚点；
2. **状态枚举硬性规约**：必须且仅能使用明确的项目阶段状态枚举标签，**严禁写成无意义的“当前状态”四个字或随意白话**：
   - `【已实施】`：已完成代码编写、技能落盘、全量测试且验证通过；
   - `【规划中】`：方案已构思、契约已规划，处于方案待确认或排期设计阶段；
   - `【实施中】`：正在执行文件写入、脚本调试或自检门禁；
   - `【已阻断】`：遇到外部依赖缺失、权限不足或明确阻断条件；
3. **简明阶段总结**：状态枚举后附带一句高密度、无客套的阶段达成总结，说明当前处于该状态的确切依据。
