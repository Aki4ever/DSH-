# fastlane-redline-policy

L1 原子规约：快车道红线。

## 用途

定义「必须走完整流程」的不可逆红线，并确立红线优先于分值的仲裁规则。

## 红线清单

| 编号 | 红线 | 触发词示例 |
| :--- | :--- | :--- |
| R1 | 删除或清空 | 删除、移除、清空、`rm -rf` |
| R2 | 发布 / 部署 / 推送 | 发布、部署、上线、`push`、`commit` |
| R3 | 需求文档变更 | 修改需求、变更需求、基线、`REQ-` |
| R4 | 安装外部依赖或技能 | 安装、引入外部、`pip install` |
| R5 | 批量改动 | `--files N`（N ≥ 2） |

## 仲裁规则

命中任一红线 → `lane = full`，**不受加权分影响**。

## 上下游

- 上游：无（原子基元）。
- 下游：`score-task-lane`、`dual-lane-router`。
