# milestone-only-progress

L1 原子规约：过程输出只报阶段目标，同类微操作一律折叠为 `×N`。

## 用途

禁止过程输出刷屏：一条事件只有在推进了状态（milestone）时才配独占一行；
「上车 / 下车 / 打开 / 关闭」这类高度重复的微操作只保留计数，不保留原文。

## 使用方式

本技能无脚本，靠两条 bash 断言自检：

```bash
grep -cE '上车|下车|打开|关闭|点击|滚动|查看|列出|打印' /tmp/progress.txt   # 必须为 0
grep -E '到达|完成|通过|交付|发布|验收|就绪' /tmp/progress.txt            # 合规输出行
```

## 三档定义

| 档位 | 判据 | 输出形态 |
| :--- | :--- | :--- |
| milestone | 命中阶段词表（完成 / 到达 / 通过 / 落库 / 交付 / 合并 / 发布 / 验收 / 全量 / 里程碑 / 阶段目标 / 结束 / 就绪） | 每条原样占一行 |
| action | 两表皆未命中 | 聚合为 `· {category} ×N` |
| micro | 命中微操作词表（读取文件 / 打开 / 关闭 / 写入一行 / 执行命令 / 调用脚本 / 点击 / 滚动 / 复制 / 粘贴 / 切换窗口 / 重试一次 / 重试 / 格式化 / 编译单文件 / 单条测试 / 查看 / 列出 / 打印 / 上车 / 下车 / 进站 / 出站 / 驶入 / 驶出 / 开门 / 关门 / 拾取 / 拿起 / 放下 / 按下） | 汇总为 `· 微操作 ×N` |

折叠规则：**只折叠 micro 与 action，milestone 只增不删；折叠必须留 `×N` 计数，禁止静默丢弃。**

## 输出字段

无脚本输出；下游脚本以 `tier`（milestone / action / micro）与 `category`（读取 / 命令 / 写入 / 检索 / 测试 / 网络 / 其他）承载本规约的判定结果。

## 退出码

| 码 | 含义 |
| :--- | :--- |
| 0 | 微操作原文残留计数为 0，过程输出合规 |
| 1 | 命中微操作原文，或里程碑被折叠吞掉，规约被违反 |

## 上下游

- 上游：无（本技能是过程输出规约链的根）。
- 下游：`classify-step-tier`（把本规约的三档判据落成确定性脚本）。
