# Prune Bloated Prompts (提示词防膨胀规约)

## Overview

本技能是 L1 原子级基础规约。任何新增的指令规则必须具备增量信息，严禁同义反复（如重复强调“必须纯中文”与“只能用汉字”）。

## Strict Rules

1. **零同义反复**：同一意图在单个上下文中只允许存在一条明确规则；
2. **剔除虚词描述**：直接使用“禁止 X”或“必须 Y”，剔除无实际约束力的形容词。
