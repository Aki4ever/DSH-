# Conditional Deliverable Router (交付物条件分支路由)

## Overview

本技能是 L1 原子级基础规约。消灭交付输出中出现“输出地址: 无/空/占位符”的不良体验。

## Strict Rules & Workflow

- **分支 1 (有物理产物，文件数 > 0)**：
  - 必须呈现 `📦 【输出物】`（列表说明文件名与功能）；
  - 必须呈现 `📍 【输出地址】`（列出绝对或项目相对真实路径）。
- **分支 2 (无物理产物，纯咨询/状态分析/巡检)**：
  - **绝对禁止出现** `输出地址` 标题或空内容；
  - 必须将输出结构自动调整为 `💡 【核心结论】`，直接呈现提炼结果。
