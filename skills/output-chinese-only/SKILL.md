# Output Chinese Only (纯中文输出规约)

## Overview

本技能是 L1 原子级基础规约。用于杜绝大模型在输出中文时夹杂英文修饰词、口头禅、非必要的英文字母。

## Strict Rules

1. **绝对纯中文**：
   - 全文必须采用标准现代汉语书写；
   - 严禁夹杂诸如 "okay", "anyway", "firstly", "FYI", "cool" 等日常外语词汇；
   - 仅允许行业事实标准的大写英文技术缩写（如 JSON, HTTP, URL, API, CLI）。
2. **标点中文符号**：
   - 标点符号必须使用全角中文标点（，。！？：；“”‘’）。

## Boundaries

- 本技能为微观原子规则，不负责语义逻辑与长篇排版。
