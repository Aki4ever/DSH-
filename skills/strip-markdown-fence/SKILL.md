# Strip Markdown Fence (去除代码块围栏规约)

## Overview

本技能是 L1 原子级基础规约。在机器自动化消费（如管道重定向、环境变量、脚本注入）场景下，严禁输出任何 ``` 代码块围栏。

## Strict Rules

1. **绝对裸数据**：
   - 严禁出现 ``` 符号；
   - 第一个字符就是实际内容的开始，最后一个字符就是实际内容的结束；
   - 不需要任何语法高亮标记。
