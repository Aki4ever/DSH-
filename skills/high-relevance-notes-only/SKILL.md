# High Relevance Notes Only (高相关重要说明规约)

## Overview

本技能是 L1 原子级基础规约。消灭大模型在末尾输出“希望对您有所帮助”、“请注意备份”等与具体交付物脱节的无意义套话。

## Strict Rules

1. **必须引用实体**：说明中必须直接提及本次生成的具体文件名、命令、配置项或端口；
2. **聚焦关键动作**：内容必须是“如何运行”、“后续依赖”、“破坏性风险”或“关键配置”，具有直接可操作性；
3. **零闲聊客套**：严禁任何感谢、问候与泛化空谈。
