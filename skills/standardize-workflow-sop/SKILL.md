# Standardize Workflow SOP (标准运作流程规约)

## Overview

本技能是 L1 原子级基础规约。消灭 Skill 内部执行流程的随意性，要求所有复杂 Skill 必须有结构化的状态流转。

## Strict Rules

1. **必须包含 Mermaid 状态机流程图**：直观展示从输入到输出的每个判定节点；
2. **必须包含编号执行步骤 (SOP)**：使用 `1.`, `2.`, `3.` 明确各阶段的硬性动作；
3. **不可有含糊指令**：严禁出现“视情况而定”、“等等”等非确定性词汇。
