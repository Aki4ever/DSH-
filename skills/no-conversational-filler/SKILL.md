# No Conversational Filler (零寒暄废话规约)

## Overview

本技能是 L1 原子级基础规约。消灭大模型常见的习惯性寒暄（如“好的”、“收到”、“没问题”、“以下是为您分析的...”等）。

## Strict Rules

1. **绝对零寒暄**：
   - 严禁任何打招呼、道歉、谢意或承接语；
   - 严禁“如上所述”、“希望对您有所帮助”等收尾套话；
   - 必须第一句话直接切入干货事实或目标数据。
