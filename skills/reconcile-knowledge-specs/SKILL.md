# Reconcile Knowledge Specs (知识库规范对拍与仲裁)

## Overview

本技能是 L2 工序动作级工具技能。用于自动化审查当前输出或待执行方案是否违背知识库 7 大规范；一旦发现冲突，强制遵循规范优先原则。

## Usage & Script

```bash
python3 skills/reconcile-knowledge-specs/scripts/reconcile_specs.py --check-all
```
