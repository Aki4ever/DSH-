本文档是系统多项目知识库的**隔离与治理总规**。依据系统元规则第九条（领域隔离防污染铁律），每个独立项目必须在此目录下建立专属子目录，严禁跨项目串扰。

---

## 🛡️ 一、多项目物理隔离铁律 (Domain Isolation Law)

1. **按工程物理隔离**：
   - 每一个独立产品/工程拥有专属目录：`knowledge/projects/<project_name>/`；
   - 项目知识库仅记录该项目特有的：世界观背景、核心故事剧情、专属美术风格、特定后端接口字典与技术参数；
2. **非游戏禁载游戏世界观红线**：
   - 当任务目标为通用 Web 工具、管理后台、小程序等非游戏业务时，**绝对禁止载入或关联游戏世界观与虚构设定**，避免大模型上下文被无谓污染导致代码设计变形；
3. **完全继承通用规范**：
   - 所有项目默认自动继承 [`knowledge/common/`](../common/README.md) 下的通用工程、交互（格式塔/别让我思考）、Unity（页面Scene/弹窗Prefab/按钮阴影）、Web 与小程序规范。
