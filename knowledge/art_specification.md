## 🎨 一、视觉风格基准与色彩矩阵

### 1. 核心视觉风格
- **整体风格**：**半写实近未来轻科幻 (Semi-Realistic Near-Future Sci-Fi)**；
- **材质质感**：以真实物理工业质感（哑光金属、高分子复合材料、碳纤维、划痕拉丝铝合金）为底，点缀微弱的以太源能自发光；
- **形体语言**：硬朗利落的倒角多边形、功能性外露结构与合理的人体工学，拒绝过度夸张漂浮的非功能性装饰。

## 📐 二、3D 资产与模型拓扑规范

### 1. 面数与拓扑预算 (以同屏中等机型为基准)

| 资产级别 | 代表类型 | 三角面峰值 (Tris) | LOD 分级规范 | 骨骼数量上限 |
| :--- | :--- | :---: | :---: | :---: |
| **特等主角 (Hero)** | 核心操控主角、特写Boss | 25,000 ~ 35,000 | LOD0 / LOD1 / LOD2 | ≤ 75 根 |
| **一等NPC (Standard)** | 常规精英怪、交互NPC | 10,000 ~ 18,000 | LOD0 / LOD1 / LOD2 | ≤ 45 根 |
| **小怪群体 (Mob)** | 场景同屏杂兵、巡逻无人机 | 3,000 ~ 6,000 | LOD0 / LOD1 | ≤ 25 根 |
| **大型建筑 (Building)** | 基地中枢、巨型星门 | 20,000 ~ 40,000 | LOD0 / LOD1 / LOD2 | 静态无骨骼 |
| **小型道具 (Props)** | 武器、箱子、终端控制台 | 800 ~ 2,500 | 仅 LOD0（视距剔除） | ≤ 5 根 |

### 2. 建模与布线规范
- **禁止非流形几何体**：禁止共边多面、内部废面、孤立顶点与重叠重面；
- **平滑组与倒角**：硬边法线必须配合合理倒角（Bevel），避免纯粹的 90 度死角硬边造成光照撕裂；
- **单位比例**：Maya / Blender / Max 导出单位必须锁定为**公制米 (Meters)**，与 Unity Transform Scale (1, 1, 1) 严格对应。

## 🧪 三、PBR 材质与贴图规范

### 1. 材质工作流
- 统一采用 **PBR 金属度/粗糙度工作流 (Metallic/Roughness Workflow)**；
- 贴图色彩空间严格区分：
  - **sRGB (开启)**：BaseColor (固有色贴图)；
  - **Linear (关闭 sRGB)**：Normal (法线贴图)、Mask/Channel Packed (遮罩打包图)。

### 2. 贴图尺寸与通道打包规范
- **最大贴图尺寸**：
  - 核心角色/关键特写：`2048x2048`；
  - 常规道具/环境物件：`1024x1024`；
  - 微型物件/UI通用精灵：`512x512` 或图集；
- **ORME 通道打包标准 (打包为单一纹理，节省采样开销)**：
  - **R 通道**：Ambient Occlusion (环境光遮蔽 AO)
  - **G 通道**：Roughness (粗糙度)
  - **B 通道**：Metallic (金属度)
  - **A 通道**：Emission Mask 或 Height (自发光遮罩或高度)

## 🖥️ 四、UI 视觉与界面排版规范

1. **画布适配基准**：
   - 基础设计分辨率：`1920 x 1080` (16:9)；
   - 适配策略：`Match Width or Height (0.5)`，所有核心交互组件必须锚定在安全可视区内；
2. **切图与精灵格式**：
   - 纯扁平矩形/底板采用 **九宫格 (9-Slice) 切片**，严禁使用整张大位图充当纯色拉伸底板；
   - 图标统一打包进 Unity SpriteAtlas (精灵图集)，杜绝零散小碎图造成 DrawCall 激增；
3. **字号阶梯规范**：
   - 标题级 (Header)：`32px ~ 40px` (加粗)；
   - 按钮与核心交互 (Button/Tab)：`24px ~ 28px`；
   - 正文与说明 (Body)：`18px ~ 20px`；
   - 提示与角标 (Tip/Footnote)：`14px ~ 16px` (禁止低于 12px 导致移动端模糊)。

## 🚫 五、美术审查冲突阻断红线 (前置阻断)

在审核任何新提交的美术资产或视觉需求时，若触碰以下红线，**前置核验直接阻断并驳回**：
1. **风格割裂**：严禁出现纯二次元日系大眼萌、美式卡通等严重背离“半写实轻科幻”的素材；
2. **暴力撞色与光污染**：禁止全局高饱和度发光泛滥（Bloom 泛光过度导致屏幕发白失真）；
3. **性能越界**：单体资产三角面或贴图分辨率超过预算上限 30% 以上且无合理 LOD 说明者，严禁合入主工程。
