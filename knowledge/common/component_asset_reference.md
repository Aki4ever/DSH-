## 🎨 二、精美可视化微组件标准库 (Reusable SVG & Layout Patterns)

为方便后续极速生成生动形象的信息图与 UI 控件，本法典提炼四大经典通用的视觉微组件版式（零外部图片依赖，支持内联矢量绘制）：

### 1. 终端发光状态卡 (Glowing Terminal Card)
- **视觉特征**：深黑背景 `#0B132B`，细边框 `#1C2A4A`，顶部三色控制圆点（红/黄/绿），绿色等宽字体命令行回显；
- **适用场景**：呈现自动化脚本执行、Git 远程同步、门禁判定与机器 Exit Code。

### 2. 多维指标数据栅格 (Metric Stat Ribbon)
- **视觉特征**：左右等分卡片，上方是小字号次级说明标签（如“双检冲突”），下方是 24px 加粗高亮彩色数字（绿色 0 / 红色 N）；
- **适用场景**：门禁量化看板、效率审计指标结算、性能基准比对。

### 3. 时间轴工序流程管道 (Timeline Pipeline Node)
- **视觉特征**：水平或垂直串联的圆环节点，通过实线连贯相通，成功节点内嵌白色勾选图标，当前节点带呼吸外发光环；
- **适用场景**：十六步执行流回溯、PRD 方案审批流转、CI/CD 构建发布链路。

### 4. 浮层抽屉与模态卡片 (Elevated Modal Sheet)
- **视觉特征**：底部 60% 黑色高斯模糊蒙层，前景卡片配 12px 圆角与扩散深度投影，操作按钮清晰分级（主白/次灰）；
- **适用场景**：破坏性操作二次防呆确认、移动端详情展开。

## 🛠️ 三、新获取组件与图控的沉淀与复用机制

1. **遇好即收 (Fetch & Capture)**：从外部官网或设计体系中吸纳全新优秀组件形态时，必须将其关键样式 Token（色值、边框、圆角、阴影、间距）沉淀至本文档或 `knowledge/common/readability_specification.md`；
2. **拒绝异构割裂**：任何外部吸收的组件，其主色与圆角必须强制对齐系统基准（主蓝/状态绿/标准圆角 8px），严禁原样照搬破坏全局一致性；
3. **图表技术指南联动**：涉及大型全景图绘制时，无条件遵循 [`docs/diagram_generation_guide.md`](../../docs/diagram_generation_guide.md) 的标准图表模版与配色决策树。
