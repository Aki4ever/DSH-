## 一、本目录放什么

| 文件 | 作用 |
| :--- | :--- |
| [`workspaces.json`](workspaces.json) | 迁移台账：源 / 目标工作区、会话清单、备份路径、回滚方式 |

## 二、为什么需要它

DSH 会话归属的唯一真相源是宿主侧的
`~/Library/Application Support/dsh-desktop/harness/storages/workspace.json`——
那是**运行态数据**，不在版本控制内，一次覆盖就无法追溯「谁曾经归过谁」。

本目录是它在版本控制内的**留痕镜像**：只记事实（源工作区、目标工作区、会话条数、
备份文件路径、回滚步骤），不复制任何会话内容本身。
