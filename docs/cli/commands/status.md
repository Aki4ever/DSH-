# `skill-pool status`

查看仓库整体 Skill 数量、合规率及与目标运行环境的链接状态概览。

## 用法
```bash
./bin/skill-pool status [--target <DIR>] [--json]
```

## 示例输出
```text
📊 Skill Pool 状态概览:
  - 仓库根目录: /Users/linqiyu/Documents/DSH/Skill池
  - 同步目标目录: /Users/linqiyu/.codex/skills (已存在)
  - 技能总数: 5
  - 规范合规: 5 个
  - 存在异常: 0 个
  - 已软链同步: 3 / 5 个
```
